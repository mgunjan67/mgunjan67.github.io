# Gunjan Mishra — Portfolio

A concise portfolio combining a cinematic dark opening, bold editorial chapters, and playful 3D character art. Interactive work showcases lead into three research entries, a short bio, and contact. Detailed photo browsing remains on its own project page.

## Run

Node.js 20 or later; no npm packages are required.

```sh
npm run dev
npm run check
npm run build
```

The static pages work at a GitHub Pages repository root. The build cleans `dist/` and copies only explicitly listed assets.

## Pages and content

- `index.html`: introduction, interactive Photo Finisher and spatial intelligence showcases, public research, bio, contact.
- `photo-finisher.html`: 25 user-approved saved comparisons, scene filters, keyboard gallery navigation, and optional feature/style explorations in closed disclosures.
- `spatial-work.html`: brief summaries of spatial understanding and construction-progress work, with original generic illustrations.
- `styles.css`: shared layout and photo interactions. `visual.css`: cinematic/editorial composition, interactive scenes, and responsive character placements.
- `experience.js`: homepage photo comparison and an original 3D renderer with pointer/keyboard rotation and illustrative construction-progress control. All geometry is invented; the scene renders only on interaction or resize.
- `app.js`: responsive navigation and optional pointer depth. `photo-lab.js` and `showcase.js`: photo interactions and neutral scene data.
- `projects.js`: source-backed content reference retained for provenance; the previous long project-note interface is no longer used or deployed.

`public-content.json` records public research sources, explicit content authorization, visual provenance, and the deployment asset list. Read `AGENTS.md` before adding content.

The user approved high-level spatial intelligence summaries and the photo collection on 2026-11-08. Employer/customer screenshots, private methods, internal names, coordinates, and unverified metrics are excluded. The approved photo collection uses neutral filenames and stripped metadata. No property addresses or third-party benchmark edits are included.

The three feature concepts were generated with ImageGen and are identified separately from the 25 saved pipeline results. The 24 style directions are browser color-grade previews, not production preset claims. Core product finishes are Bright natural, Soft natural, and Warm natural.

The portrait selected by the user on 2026-11-08 leads the hero. The thinking, laptop, and greeting poses were rebuilt with built-in ImageGen using that selected face as the identity reference. They appear in research, about, contact, and project introductions. Company and workplace names, employment wording, and the CV request are removed from the portfolio. Raw portrait references are not deployed. Pointer depth is disabled for reduced-motion preferences and touch devices. Research entries link directly to their public preprints. Contact links open email; the site uses no analytics or third-party runtime requests.
